# Dinero Releases Archive - Retired

This repository is retired and no longer publishes current Dinero downloads.

Current canonical project:

- Source: https://github.com/DineroLabs/dinero-v8
- Downloads: https://github.com/DineroLabs/dinero-v8/releases

Do not use the v2.x assets in this repository for new installs. They are kept only as historical artifacts for provenance and old debugging.

Release policy going forward:

- `DineroLabs/dinero-v8` is the single canonical source and release lane.
- Release candidates remain pre-releases.
- Stable downloads will be published from `DineroLabs/dinero-v8/releases`.
